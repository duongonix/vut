# Vut documentation

End-user documentation for the Vut programming language and toolchain. These
pages are published to the public repository
[`duongonix/vut`](https://github.com/duongonix/vut).

- [Installation](installation.md) — install, verify, upgrade and uninstall Vut.
- [Getting started](getting-started.md) — first program, projects, imports.
- [Command line](cli.md) — `vut` and `vpm` commands.
- [Language guide](language.md) — a tour of the language.
- [Standard library](stdlib.md) — the official modules.
- [Troubleshooting](troubleshooting.md) — linker, SDK and `vut doctor` issues.

The normative language, compiler and deployment specifications live in the
source repository under `specs/` and are not part of this documentation set.
